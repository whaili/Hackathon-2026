# Ideas 提交区

三人各自提交 Hackathon 候选项目创意到这个目录，之后综合评估选出最终做哪个。

## 提交格式

每人一个文件（建议用英文短横线命名，如 `your-idea-name.md`），内容不强制统一模板，但建议至少说明：

- 一句话简介
- 核心玩法
- AI 在其中扮演什么角色、为什么不可替代
- 差异化：市面上有没有类似产品
- 首版范围：3 天 2 夜能不能交付
