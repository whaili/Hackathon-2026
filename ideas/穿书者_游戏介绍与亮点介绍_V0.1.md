# 《穿书者》游戏介绍与亮点介绍

**版本：V0.1｜定位：游戏概念介绍初稿｜首部体验作品：《穿成恶毒女配后，我不按剧情走了》**

## 一、先用一句话说清楚

《穿书者》是一款沉浸式语音互动小说游戏：你魂穿进一本网文的开局之夜，扮演那个原本要被全城唾弃的恶毒女配；你可以用自己的话和书中人物交谈、承诺、争辩，把原本注定的羞辱结局，走成属于你的另一种人生。

它不是把小说念给你听，也不是只给你几个写好的选项；它让你真的开口，并被书中人听见。

## 二、对玩家的第一句话

**你昨晚熬夜追更的那本小说，今天由你亲自改写。**

睁开眼，你已经穿进了书里。侍女在门外低声催促：陷害女主的东西已经送出去了，宴会马上开始。这一夜过后，原著里的“你”会身败名裂——除非你选择不按剧情走。

## 三、游戏是什么？

《穿书者》是一款以语音为核心的沉浸式互动小说游戏。玩家单人进入一本小说的开局之夜，魂穿为书中的某个角色，并通过说话、文字和行动，与书中人物建立关系、改变事件走向。

它保留了网文最让人上头的部分：穿书、身份错位、预知剧情、逆天改命；但它不让玩家只是在屏幕外着急。在这里，你必须亲自开口。

一局的基本体验可以概括为：

1. 进入书本：短暂了解自己穿成了谁，以及这个角色在原著里的可悲结局。
2. 遇见人物：书中人带着自己的目的、秘密和偏见与你相遇。
3. 自由表达：你可以解释、撒谎、谈判、承诺，也可以直接拒绝原剧情。
4. 改变因果：你的话会被听见，也会留下后果；有些人因此信任你，有些人因此利用你。
5. 章节结算：哪些人活下来了，哪些关系变了，这一夜到底偏离了原著多少。

## 四、首部体验作品：《穿成恶毒女配后，我不按剧情走了》

### 4.1 开场之夜

你睁眼醒来，发现自己穿进了昨晚追到凌晨的那本小说。

原著里，你扮演的相府千金会在今晚的宫宴上陷害女主，被当场拆穿，从此失去所有人的信任，成为全城笑柄。

但现在，侍女正在门外催促：

“小姐，您吩咐准备的东西已经送去了。宴会就要开始，再不走就来不及了。”

你可以选择多种开口方式，例如：

- 立刻撤回：让侍女把东西追回来，今晚按兵不动。
- 当面质问：问清楚这件事到底是谁安排的，目的何在。
- 主动赴宴：先去宫宴，假装一切照旧，随机应变。
- 直接坦白：告诉女主真相，赌她愿不愿意信你一次。
- 反向设局：既然有人想借你的手害人，那就先把证据留下。

每一种说法都会引发不同的回应；人物听见的是你的语气、承诺和选择，而不是系统猜中了某个关键词。

### 4.2 你拿到的处境

作为穿书者，你拥有原著记忆，却没有原著主角的光环和运气。

| 你拥有的           | 你面对的              |
| -------------- | ----------------- |
| 知道今晚之后会发生什么    | 没有人相信你突然变了一个人     |
| 熟悉主要人物的大致性格    | 原身早已把这个家得罪遍了      |
| 可以决定今晚的第一句话怎么说 | 事情已经开始推进，不是你想停就能停 |
| 有机会救下本该牺牲的人    | 救人的代价可能是把自己搭进去    |

这不是“知道答案就能赢”的开局。知道剧情只是起点，真正难的是：在一个不信你的世界里，把话说出去，并让人愿意听。

### 4.3 故事示例：你可以怎样改写这一夜

如果选择先去见女主，你可以当面承认布置是自己经手的，但请求她配合演一场戏，把幕后之人引出来。

如果女主相信你，她会在宫宴上按你的说法行事，反将一军；如果她不信，宫宴上的陷阱依然会落下，只是这一次，证据已经提前握在你手里。

如果选择什么都不做，这局也会有结局：你躲过了主动作恶，但原身留下的隐患、别人的布局和宫宴本身的危机，仍然会推着你往前走。

也就是说：不按剧情走，不等于会自动变好；但它第一次把选择权交回到你手里。

## 五、核心亮点

### 亮点一：不是替主角选台词，而是由你开口当主角

传统互动小说给玩家几个写好的选项；《穿书者》让玩家用自己的话说。

系统识别的是意图、承诺和行动倾向，而不是只匹配几个关键词。同样是拒绝陷害，有人威胁、有人解释、有人谈条件，书中人物的反应也会完全不同。

同时保留文字输入和推荐选项，避免玩家卡住，也避免在不方便说话时无法继续。

### 亮点二：兑现“我早就想改这段剧情了”

网文改编最上头的动机，是让玩家介入一个令人不甘的节点。

因此每一章都要给玩家一次可感知的改变：谁被救下了，关系如何变化，命运到底偏离了原著多少。关键事件有边界，表达可以自由；玩家可以写自己的台词，但不能一句话就让世界规则崩塌。

### 亮点三：书里的人会记得你做过什么

你第一章替一个小人物说过话，第三章遇险时，他可能会站出来帮你；你随口许下的承诺，之后也会被追问。

比起简单的好感度数字，更有代入感的是：

“上次你说过，不会再把我一个人留下。那这次呢？”

这些记忆必须来自游戏里真实发生过的事件，不能凭空编造玩家的经历。

### 亮点四：表达自由，但世界规则稳定

玩家可以自由说话，但世界规则和人物立场保持稳定。

你不能因为说了一句“我现在是皇帝”，就直接获得权力；身份、财富和信任都要通过剧情行动去争取。这恰恰保证了沉浸感不崩：玩家自由，世界可信。

### 亮点五：语音为主，文字兜底，不强迫开口

想说就说，不方便就用文字；不必担心发音、方言或环境噪音被评判。

系统不会根据声线、停顿或语气来判断玩家是否在撒谎；真正影响局势的是选择与行动，而不是声音表现。所有关键剧情都提供等义字幕，不依赖玩家听辨音色。

### 亮点六：为穿书题材与网文改造而设计，首作为原创示范

产品框架既支持原创穿书剧本，也支持未来接入已取得合法授权的网文 IP。

首部体验作品《穿成恶毒女配后，我不按剧情走了》是原创示范故事，用来验证“开口改剧情”的核心循环，而不是复述某一既有小说。若未来改编具体的现有网文作品，必须单独取得相应改编授权，这是不可跳过的合规前提。

## 六、它和传统互动小说有什么不同？

| 传统互动小说或语音玩法       | 《穿书者》体验              |
| ----------------- | -------------------- |
| 主角台词由作者写死，玩家只能二选一 | 玩家可以自己组织语言，表达意图与承诺   |
| 语音多用于朗读或简单命令      | 语音用于谈判、争辩、请求和建立关系    |
| 内容是把小说念或演给玩家听     | 玩家可以改变关键事件的走向        |
| 聊天机器人无边界，容易偏离故事   | 事件有剧本边界，表达可自由，规则稳定   |
| 关系变化只表现为好感度数值     | 人物记得你做过的事，并在后续回访     |
| 网文改编常依赖未授权复述      | 本产品区分原创示范与授权 IP，边界明确 |

## 七、玩家为什么可能会被吸引？

### 对穿书题材读者

你终于不用只在评论区说“作者你不许这么写”。你可以进书里，替那个最让人心疼的角色说一句话。

### 对角色扮演玩家

你可以演出截然不同的女配：可怜、狠戾、委屈、善于谈条件，或者干脆承认错误、重新开始。

### 对关系叙事玩家

你会看见自己的选择如何改变别人对你的称呼：从“那个恶毒的女人”，变成“那天没有推我下去的人”。

### 对不方便开口的玩家

文字输入和推荐选项始终可用；环境嘈杂、不想说话或只想先看剧情时，都不会被拒之门外。

## 八、适合对外使用的宣传文案

### 主宣传语

**你昨晚熬夜追更的那本小说，今天由你亲自改写。**

### 备选宣传语

- 穿书不是看戏，是亲自上场。
- 这一夜之后，原著里的你会身败名裂，除非你选择不按剧情走。
- 你可以降低声量、伪装顺从、转身背叛，也可以第一次说出真相。
- 书里的人不会记住你读了多少遍原著，只会记住你为他们做过什么。
- 不是所有穿书都能改命，但这一次，话是你说的。

### 对外简介短版

沉浸式语音互动小说《穿书者》首部体验作品《穿成恶毒女配后，我不按剧情走了》开启概念测试。

你将在宫宴前夜魂穿为相府千金，也就是原著里那个陷害女主、声名狼藉的恶毒女配。距离事发只剩一晚。

你可以撤回布置、当面坦白、反向设局，也可以继续照原剧情走下去。你所说的每一句话都会被书中人听见；而他们记住的，不是你读过多少遍原著，而是你为他们做过什么。

### 产品介绍长版

《穿书者》是一款面向穿书、重生、逆袭等网文题材的沉浸式语音互动小说游戏。玩家单人魂穿为书中的关键角色，用语音或文字与人物交流，通过自由表达、承诺与行动，改变原本注定的剧情走向。

产品强调三件事：第一，玩家可以自己说话，而不是只在写好的选项里挑答案；第二，每一章都要兑现一次可感知的改变，让玩家真正感到“这一段原本不该这样”；第三，书中人物会记住真实发生过的事件，并在后续章节回访玩家的选择。

首部体验作品采用原创穿书女配剧本作为示范故事，验证核心循环。若未来接入真实网文 IP，则需在取得合法授权后单独改编。

## 九、当前版本的产品边界

这份介绍聚焦产品定位和首作亮点，不等同于完整 PRD，也不代表所有体验已经通过用户测试。

当前建议首版保留：单人魂穿、语音自由输入、文字与推荐选项兜底、关键事件边界、关系记忆、章节结算、多个剧情走向。

当前建议暂不承诺：多人实时连麦竞演、完全开放的自由世界、一句话改写世界规则、声纹测谎、语气实时判谎、付费购买关键结局，以及对既有网文进行未授权复述。

正式开发前需要进一步完成：首作三章完整台词、人物关系表与事件边界表、意图识别与剧本回应的衔接规则、语音识别延迟方案、字幕与可访问性测试、内容安全审核，以及可选 IP 的授权确认。

## 十、最后一句话

**《穿书者》不是把网文念给你听，而是把“如果当时我在书里”这件最让人上头的事，交给玩家亲自开口完成。**
