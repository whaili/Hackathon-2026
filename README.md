# Hackathon-2026

七牛云第五届 1024 Hackathon 参赛项目：基于"灵矽"（Lingxi/Xrobot）语音 AI 平台做一款语音类游戏。

4. [src/game_backend/README.md](src/game_backend/README.md) — 游戏后端技术文档：架构、部署、灵矽/MCP 控制台配置、开发、测试、端到端验证方法、已知问题
