# 《寻凶者》游戏介绍与亮点介绍

**版本：V0.1｜定位：游戏概念介绍初稿｜核心项目：首案《今夜，请国王指认凶手》**

## 一、先用一句话说清楚

《寻凶者》是一款四人语音悬疑剧场：玩家先共同制定“什么样的人应该被审判”，再调查一场王室命案；当所有证据最终指向刚刚加冕的新王时，玩家必须决定——是让国王继续审判，还是让他接受自己亲手写下的法律。

## 二、对玩家的第一句话

**你刚刚成为这座城的救星。现在，请亲手指认凶手。**

但请记住：这座城最不能接受的答案，可能就是你自己。

## 三、游戏是什么？

这是一个以语音交流为核心的多人悬疑故事游戏。四名玩家共同进入一个正在发生危机的世界，每个人拥有不同身份、秘密和权力。玩家需要通过说话、提问、公开证据、质证和共同决策，推动故事向前。

它保留剧本杀最有魅力的部分：角色代入、信息差、悬念、秘密和当面对话；但它不把最终目标停在“找出谁是凶手”。在《寻凶者》中，玩家还要回答三个更难的问题：

1. 事实究竟是什么？
2. 不知情造成的伤害，应该承担什么责任？
3. 谁拥有审判别人的资格？

## 四、首案故事：《今夜，请国王指认凶手》

### 4.1 故事开场

风暴即将围城。新王黎朔刚刚带领城邦解决饥荒、修复水道，成为所有人眼中的救星。

加冕礼结束后，他发布第一道王令：

> “旧王死得不明白，这座城就不会真正安全。无论凶手是谁，我都将剥夺他的王冠与姓氏。”

四名玩家作为与旧案有关的人，被召集到王宫调查旧王之死。

就在调查开始时，一封旧王留下的遗嘱被打开：

> “如果你听见这封遗嘱，孩子，你一定已经逃得足够远了。”

与此同时，旧王遗物中的路口记录，与新王随身佩刀的旧缺口吻合。

一场追查，开始变成一场审判。

### 4.2 故事的核心真相

很多年前，旧王听到一个预言：自己的孩子终将杀死自己。为了逃避预言，他把年幼的孩子送出王宫，隐瞒了孩子的身份。

多年后，孩子黎朔也得知了类似的预言。为了不伤害养父，他选择离开故乡，逃得越远越好。

旧王晚年后悔，开始寻找失散的孩子。一个人在寻找，一个人在逃离。两个人最终在一条狭窄的路口相遇，却都不知道对方的真实身份。

冲突发生了。黎朔杀死了拦路的车队首领，而那个人正是他的生父。

后来，黎朔凭借救城功绩成为新王，并亲自主持对旧王之死的调查。

他为了躲避弑父的命运，最终亲手走到了命运安排的路口；他为了追查真相，最终把审判引向了自己。

但游戏不会简单告诉玩家“黎朔是坏人”。玩家必须进一步判断：

- 他是否知道对方是自己的父亲？
- 不知情造成的死亡，是否等同于谋杀？
- 逃亡、防卫与权力之间，责任应该如何划分？
- 一个人是否可以继续审判别人，同时拒绝审判自己？

## 五、核心亮点

### 亮点一：玩家亲手制定的法律，会回来审判玩家

普通推理游戏通常先给出规则，再让玩家寻找答案。《寻凶者》反过来：玩家在开局先共同制定审判标准。

例如，四位玩家需要讨论并确定：

- 物证和证词哪个更重要？
- 没有杀人意图，是否可以被判定为重罪？
- 王室成员是否享有特殊豁免？
- 隐瞒真相的人，是否应该失去审判资格？
- 审判必须在今晚结束，还是应该等待更完整的证据？

这些不是装饰性问答，而是本局真正生效的规则。

当后续证据指向新王时，系统会把玩家开局说过并确认的规则重新放回桌面：

> “你刚才说，身份再高，只要证据确凿，就必须受审。现在，这条规则是否也适用于国王？”

玩家不是被剧情突然惩罚，而是被自己亲手建立的标准逼到最后。

### 亮点二：不是投票选凶手，而是决定谁有资格审判

在普通剧本杀中，结尾通常是投票找出凶手。

《寻凶者》把结尾拆成三层：

1. **确定事实**：旧王是否死于路口冲突，新王是否就是当年逃亡者，死者是否是他的生父。
2. **判断责任**：这是故意杀人、误杀、防卫过当，还是由隐瞒、恐惧和权力共同造成的悲剧。
3. **决定审判权**：由新王继续主持、由继承人接管、由四人组成临时审判庭，或交给城邦公开裁决。

所以玩家最终讨论的不是“他该不该死”，而是：

> **谁有资格决定他的命运？**

### 亮点三：王令不是剧情台词，而是玩家自己写下的约束

新王每一幕都可以发布一条王令，例如：

- 所有证人必须公开完整证词。
- 隐瞒关键事实的人不得继续主持审判。
- 王室成员不得干涉证据。
- 任何人不得以“不知情”为唯一免责理由。
- 审判必须在今晚结束。

王令发布后不能随意撤销，并会影响后续的发言、质证、证据公开和审判流程。

如果新王自己曾经发布“隐瞒身份者不得主持审判”，后续证据又证明他一直没有主动调查自己的身世，那么他不是被系统剥夺权力，而是被自己写下的王令限制。

### 亮点四：真相揭晓不是结束，而是游戏真正开始

确认新王就是当年杀死生父的人之后，玩家不会直接进入结局。

新王可以选择：

- 继续自证：强调自己不知道对方身份，没有弑父意图。
- 继续执掌审判：承认自己涉案，但认为城邦不能在风暴前失去国王。
- 交出王印：承认自己不能要求别人遵守自己不愿接受的法律。
- 要求所有人共同受审：因为隐瞒、沉默与保护共同维持了这场悲剧。

这些不是“正确选项”和“错误选项”，而是不同的责任观、权力观和关系选择。

### 亮点五：每个玩家都拥有一条不能被国王控制的权力线

四个角色不是“一个主角加三个辅助”。

| 角色 | 玩家掌握的权力 | 玩家面临的代价 |
|---|---|---|
| 新王黎朔 | 发布王令、控制审判程序 | 公开真相可能失去王位 |
| 继承人栖白 | 启动继承程序、接管王权 | 可能继承一个被真相污染的王座 |
| 守门人迟衡 | 证明新王真实身份 | 曾经为保护孩子伪造身份 |
| 旧王近卫闻烬 | 证明路口冲突与死亡经过 | 当年曾放走逃亡者并隐瞒事实 |

每个人既有能改变局势的能力，也有必须面对的代价。其他玩家不是单纯帮助揭露国王，而是拥有真正限制、推翻或接管王权的可能。

### 亮点六：不靠强行反转，而靠证据链和玩家早期选择

故事的核心身份反转必须由多条证据共同成立：

- 旧王遗嘱中的称呼。
- 送养与寻亲记录。
- 车队行进路线。
- 佩刀缺口与伤口记录。
- 近卫证词。
- 守门人的隐瞒。

任何一条线索都不能单独宣布“你就是凶手”。玩家必须通过语音讨论，将证据拼接出完整关系。

同时，开局制定的审判规则、发布过的王令和玩家主动做出的承诺，会在后期重新生效。因此，玩家会记得：

> “这是我们自己说过的话。”

## 六、它和普通剧本杀有什么不同？

| 普通剧本杀体验 | 《寻凶者》体验 |
|---|---|
| 作者预设凶手，玩家寻找答案 | 玩家共同定义什么叫责任与定罪 |
| 线索主要用于证明谁是凶手 | 线索还会决定谁拥有审判权 |
| 结尾投票结束推理 | 真相揭开后进入权力与责任博弈 |
| 角色秘密主要用于隐藏动机 | 角色拥有不同权力，能改变流程 |
| 反转是“原来你是凶手” | 反转是“你制定的法律现在审判你” |
| 结局更偏向还原过去 | 既还原过去，也决定如何面对过去 |

## 七、玩家为什么可能会被吸引？

### 对悬疑玩家

你不只是猜中一个身份，而是要判断一条完整因果链：谁做了什么，谁隐瞒了什么，谁因此获得权力，又是谁因此失去选择。

### 对角色扮演玩家

你可以扮演一个不愿意认罪的国王、一个想要王位却不想继承罪责的继承人、一个为保护孩子撒过谎的人，或一个必须在忠诚与事实之间选择的近卫。

### 对关系叙事玩家

游戏不会强迫你原谅谁。你可以继续相信一个犯错的人，也可以选择离开；你可以承认对方的责任，同时不否定他曾经对你的爱。

### 对语音社交玩家

关键不是快速抢麦或表演声音，而是当面做出承诺、请求解释、公开证据和争夺审判权。语音让玩家听见彼此犹豫、坚持和改变立场的过程，但系统不会根据声线或语气判断谁在撒谎。

## 八、适合对外使用的宣传文案

### 主宣传语

> **你刚刚成为这座城的救星。现在，请亲手指认凶手。**

### 备选宣传语

- 你制定的第一条法律，最后会审判你自己。
- 真相会指向王座，但谁有资格摘下王冠？
- 他不是在逃避审判，他是在决定审判是否真的存在。
- 你可以继续当国王，也可以让法律第一次对所有人平等。
- 这不是找出谁杀了旧王，而是决定一个人该为不知道的事承担什么。

### 对外简介短版

四人语音悬疑剧场《寻凶者》首案《今夜，请国王指认凶手》现已开启概念测试。

新王加冕后的第一道王令，是找出杀死旧王的凶手。四位玩家将分别扮演新王、王室继承人、守门人和旧王近卫，在语音交流中调查一场被隐瞒多年的王室命案。

但随着证据逐步拼合，所有人都会发现：这不是一场寻找别人的审判。新王可能就是当年杀死生父的人，而最先制定审判规则的人，也将成为规则的第一个被审判者。

### 产品介绍长版

《寻凶者》是一款四人语音悬疑剧场，融合角色代入、信息博弈、共同调查与权力抉择。玩家在每局开始时共同制定审判标准，之后通过语音讨论、证据公开、口供质证和王令执行推进故事。

游戏的核心不是找出一个作者预设的凶手，而是让玩家参与定义“什么是责任”“什么可以被原谅”“谁拥有审判别人的资格”。每一个早期选择，都可能在后期反过来约束玩家自己。

首案《今夜，请国王指认凶手》借鉴《俄狄浦斯王》中“为了逃避命运而走向命运”的悲剧结构，讲述一个刚刚成为救世主的国王，如何在追查旧王死因的过程中发现自己与案件的关系，并决定是否让自己的王冠接受审判。

## 九、当前版本的产品边界

这份介绍聚焦游戏定位和首案亮点，不等同于完整PRD，也不代表所有机制已经通过用户测试。

当前建议首版保留：四人语音、开局规则制定、王令系统、多角色权力线、证据链、事实与责任分离、审判权选择、多个责任结局。

当前建议暂不承诺：海量剧本、自动AI判谎、实时语音情绪识别、强制恋爱关系、玩家必须被淘汰、付费改变结局或大型3D场景。

正式开发前需要进一步完成：四份完整角色本、逐幕证据卡、王令与审判流程图、结局台词、语音字幕、桌面试玩和内容安全审核。

## 十、最后一句话

**《寻凶者》不是让玩家找出谁是凶手，而是让玩家亲手建立一套审判别人的规则，再看这套规则是否真的愿意对所有人平等。**
