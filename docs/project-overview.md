## 这是什么项目

七牛云第五届 1024 Hackathon 的参赛项目。要做一款基于"灵矽"（Lingxi/Xrobot，七牛云的语音 AI 交互平台）
的**语音类游戏**。

## 活动关键信息

- 活动：七牛云第五届 1024 Hackathon，2026.10.23 启动，3 天 2 夜，2026.10.26 09:00 截止开发
- 团队归属："产品研发组"（研发赛道），1-3 人自由组队
- 作品提交硬性要求：
  - 基于 PR 提交每次变更，保留完整协作/创作痕迹；仅最后一天一次性提交视为不合格
  - 若基于现成 codebase 开发，须在写自己代码前为 codebase 打 `v0` tag，否则作品判定无效、取消资格
  - 完整交付需包含：全部源代码、运行说明、架构设计文档、demo 视频，上传至 GitHub
- 评分维度（研发赛道）：商业价值&产品设计 50% / 架构设计 20% / AI 价值呈现 15% / AI 工程效率 15%
  （**商业价值&产品设计权重最高，产品差异化是决定胜负的关键因素**）
- 原始议题/规则 PDF 为内部资料，已阅读完毕后删除，不进版本库（见 `.gitignore`）

## 当前产品方向

**灵矽应用：做一款语音类游戏；具体方案仍在团队 Ideas 评审中。**

- 官方要求：不能是"跑团"类玩法（开放式叙事、阵营讨论推理、无明确单局胜负判定）；狼人杀只是示例，不限定
  具体玩法
- 团队偏好：优先不强制需要硬件的项目；差异化 > 单纯炫技；工期可控 > 规则完整度（1-3 人、3 天 2 夜）

已有候选方案及其完整提案见 [../ideas/README.md](../ideas/README.md)，统一评估见
[../ideas/evaluation.md](../ideas/evaluation.md)。

## 曾评估后放弃的方向

- **AirPlay 语音控 code agent**（通过语音指挥 Claude Code / 其他 code agent 编程，画面投到电视）：
  评估下来 AirPlay 要求同局域网，且 macOS 自带投屏零开发量，技术含量实际在"语音转指令驱动 agent"而非
  AirPlay 本身；若执行层换成远程/云端，应该用 WebSocket + xterm.js 网页终端做远程展示，而不是硬凑
  AirPlay。最终判断该方向差异化和可做深度不如语音游戏，已放弃，仅作架构对比参考保留在历史讨论中。
