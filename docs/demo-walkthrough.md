# 《别让它听见》双人序章演示

## 演示承诺

给异地朋友或情侣一个可以立即分享的语音密室：两人各持一半线索，必须交流；监听者会学习说法，
迫使他们换一种表达，最后共同决定带走什么。当前是免费序章原型，付费和用户付费意愿尚未验证。

## 演示顺序

1. 打开首页，创建双人房间，复制邀请链接给第二个浏览器。两人使用不同代号加入。
2. 对照两边页面：现场员看到符号与声音特征的映射，监听员只知道目标符号。分别开启麦克风。
3. 监听员说“授权”加当前安全符号；现场员说“校准”加对应特征。强调答案来自交换线索。
4. 第一阶段后，展示监听者学会了刚才说过的词，并在频道里模仿同伴。监听员说“识别伪装，安全符号是”加当前安全符号，
   现场员使用另一种描述校准。强调玩家说过的话改变了下一阶段的规则。
5. 最后分别阅读两方的新信息，协商是否保留档案。两人各说“确认撤离”或“保留档案”。
   选择不一致时继续协商；一致后展示共同结局和下一章预告。不要把预告描述成已经可购买的章节。

可选展示：关闭一位玩家页面，说明倒计时暂停；用原代号重新加入，角色与线索恢复，计时继续。
测试身份目前按代号恢复，尚未实现公开服务所需的身份防冒用。

## 自动生成证据与视频

见 [测试工具手册](../src/game_backend/tools/README.md#演示录制)。建议使用线上地址和新的产物目录运行
`--continuous --record-video`，随后用 `make_voice_demo.py` 生成分屏 MP4。

录制是实际 Chromium 页面；输入音轨来自测试时使用的合成语音。灵矽 ASR、游戏状态与结局是真实运行结果，
不是预先制作的页面动画。`report.json` 保留实际转写、状态事件与会话次数，截图可用于答辩材料。

## 答辩中可以证明与不能证明的内容

- 已证明：不同私有线索、双人角色校验、语音改变后续规则、共同选择产生不同结局、独立设备持续语音链路。
- 已覆盖：确定性回归、真实 HTTP/WebSocket、浏览器麦克风及真实灵矽识别，附机器报告和录制。
- 尚待验证：真人趣味性、自然抢话体验、真实扬声器回声、10–15 分钟实际时长、章节付费意愿。
- 商业路径：免费序章与章节内容售卖是假设，现阶段展示可继续讲述的故事入口，不展示虚构用户或收入。
